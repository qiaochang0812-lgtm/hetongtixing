# 提醒

客户合同到期提醒（安卓 App）。说一句话或打字，说清签订日和到期日，应用整理成合同并保存；
到期前一个月、一周和到期当天早上 9 点，用系统通知提醒（应用不用打开）。

## 用 GitHub 生成 APK

1. 仓库里只放两样：本 zip，和 `.github/workflows/build-apk.yml`。
2. 打开仓库的 **Actions** → **Build Android APK**，等它跑完（约 5～8 分钟）；也可以点 **Run workflow** 手动触发。
3. 进入这次运行，页面最下面 **Artifacts** 里下载 `qiqi-apk`，解压得到 `app-release.apk`，传到手机安装。

之后每次上传新代码都会自动重新构建。`qiqi.keystore` 是固定签名，用同一个文件签名的新版本可以直接覆盖安装旧版，不用卸载（卸载会丢合同数据）。

## 使用提示

- 第一次保存合同时会请求通知权限，请允许。
- 华为手机：设置 → 应用和服务 → 应用启动管理 → 提醒 → 改为「手动管理」，打开「允许后台活动」，否则系统可能在后台清掉提醒。
- 合同保存在应用里，页面底部有「导出备份 / 导入备份」。
- 手机应用内不能直接调用语音识别，用输入法键盘上的话筒说话即可。

## 本地开发

```bash
npm install
npm run dev      # 浏览器预览，提醒功能仅在安卓 App 里有效
```
